# コンテナランタイム自作学習プラン

このドキュメントでは、ミニコンテナランタイムの実装を通じて、コンテナ技術を体系的に学ぶためのロードマップを提案する。

## フェーズ1: 隔離の基礎 (Namespaces) - **現在地**

プロセスをホストから隔離する技術を学ぶ。

- [x] **UTS Namespace**: ホスト名の隔離 (実装済み)
- [x] **PID Namespace**: プロセスIDの隔離 (実装済み)
- [x] **Mount Namespace**: ファイルシステムマウントの隔離 (実装済み)
- [ ] **Network Namespace**: ネットワークスタックの隔離 (実装中)
    - `CLONE_NEWNET` フラグの追加
    - コンテナ内でのループバックインターフェース(`lo`)の有効化
- [ ] **User Namespace**: ユーザーID/グループIDの隔離
    - root権限なしでのコンテナ実行 (Rootless containers) の理解

## フェーズ2: ファイルシステムとルート (Rootfs)

コンテナのファイルシステム環境を構築する技術を学ぶ。

- [x] **chroot**: ルートディレクトリの変更 (実装済み)
- [ ] **pivot_root**: `chroot` よりセキュアなルート変更方法への移行
    - `old_root` のアンマウントと分離
- [ ] **Mounts**: 特殊ファイルシステムのマウント
    - `/proc`, `/sys`, `/dev`, `/tmp` の適切なマウント処理
- [ ] **OverlayFS**: イメージレイヤーの仕組み
    - 読み取り専用レイヤーと書き込み可能レイヤーの結合 (Dockerイメージの仕組み)

## フェーズ3: リソース制限 (Cgroups)

コンテナが使用できるリソース（CPU、メモリなど）を制限・管理する技術を学ぶ。

- [ ] **Cgroups v2**: 最新のCgroup階層構造の理解
- [ ] **メモリ制限**: コンテナごとのメモリ使用量の上限設定
- [ ] **CPU制限**: CPU使用率やコアの割り当て
- [ ] **PIDs制限**: フォーク爆弾 (Fork Bomb) 対策

## フェーズ4: ネットワーク構築

隔離されたネットワーク名前空間と外部との通信を確立する。

- [ ] **Veth Pair**: 仮想イーサネットペアの作成とコンテナへの接続
- [ ] **Bridge**: ホスト側のブリッジネットワーク構築
- [ ] **IP Address Management (IPAM)**: コンテナへのIPアドレス割り当て
- [ ] **Routing/NAT**: コンテナから外部ネットワークへの通信 (iptables/nftables)

## フェーズ5: セキュリティと権限

コンテナのセキュリティを強化する技術を学ぶ。

- [ ] **Capabilities**: 特権（root権限）の細分化と不要な権限の削除
- [ ] **Seccomp**: システムコールのフィルタリング
- [ ] **AppArmor / SELinux**: 強制アクセス制御 (MAC) の適用

## フェーズ6: OCI標準への準拠 (Advanced)

業界標準仕様 (Open Container Initiative) に準拠させる。

- [ ] **OCI Runtime Spec**: `config.json` の読み込みと仕様への準拠
- [ ] **Lifecycle**: `create`, `start`, `kill`, `delete`, `state` コマンドの実装
- [ ] **runc 互換**: Docker/Podman から呼び出せるようにする

## 推奨学習ステップ

まずは **フェーズ1 (Network)** と **フェーズ2 (pivot_root)** を完了させ、次に **フェーズ3 (Cgroups)** に進むことを推奨する。
これらはコンテナの「隔離」と「制限」という最も基本的な要素であるためである。
