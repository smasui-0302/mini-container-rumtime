# ミニコンテナランタイム実装ドキュメント

このドキュメントでは、ミニコンテナランタイムの現在の実装について説明します。

## 概要

このプロジェクトは、コンテナが内部でどのように動作しているかを理解するための学習用として設計された、Go言語によるシンプルなコンテナランタイムです。

## アーキテクチャ

このアプリケーションは、Linux名前空間（Namespaces）をセットアップするために、自身のバイナリを再実行するモデルを採用しています。

### エントリーポイント (`main`)

`main` 関数はエントリーポイントとして機能し、第1引数に基づいて処理を振り分けます。
- `run`: コンテナ作成プロセスを開始します。
- `child`: 新しい名前空間内で実行されるプロセス（コンテナ化されたプロセス）です。

### `run` 関数

`run` 関数は、隔離環境のセットアップを担当します。

1.  **再実行 (Re-execution)**: 現在のバイナリ (`/proc/self/exe`) を `child` 引数付きで実行します。
2.  **名前空間の隔離**: `syscall.SysProcAttr` を使用して `Cloneflags` を設定し、以下のLinux名前空間を有効にします。
    -   `CLONE_NEWUTS`: ホスト名とNISドメイン名を隔離します。
    -   `CLONE_NEWPID`: プロセスID番号空間を隔離します。
    -   `CLONE_NEWNS`: マウント名前空間（ファイルシステム）を隔離します。
3.  **IOストリーム**: Stdin、Stdout、Stderr を現在のプロセスに接続し、対話を可能にします。

### `child` 関数

`child` 関数は、`run` によって作成された隔離環境内で実行されます。

-   現在は、PIDの隔離を実証するために自身のプロセスID (PID) を出力します。
-   *注: 将来の実装では、ここでユーザーが要求したコマンドを実行し、ファイルシステムのセットアップ（chroot/pivot_root）を行う予定です。*

## 使用方法

```bash
go run main.go run [args...]
```

これにより `run` 関数がトリガーされ、新しい名前空間で `child` プロセスが生成されます。
