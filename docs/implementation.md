# ミニコンテナランタイム実装ドキュメント

このドキュメントではミニコンテナランタイムの現在の実装について説明する。

## 概要

このプロジェクトはコンテナが内部でどのように動作しているかを理解するための学習用として設計されたGo言語によるシンプルなコンテナランタイムである。

## アーキテクチャ

このアプリケーションはLinux名前空間（Namespaces）をセットアップするために自身のバイナリを再実行するモデルを採用している。

### エントリーポイント (`main`)

`main` 関数はエントリーポイントとして機能し第1引数に基づいて処理を振り分ける。
- `run`: コンテナ作成プロセスを開始
- `child`: 新しい名前空間内で実行されるプロセス（コンテナ化されたプロセス）

### `run` 関数

`run` 関数は隔離環境のセットアップを担当する。

1.  **引数の解析**: `<rootfs>` `<cmd>` `[args...]` を受け取り`child`プロセスへ渡す準備を行う
2.  **再実行 (Re-execution)**: 現在のバイナリ (`/proc/self/exe`) を `child` 引数付きで実行する
3.  **名前空間の隔離**: `syscall.SysProcAttr` を使用して `Cloneflags` を設定し以下のLinux名前空間を有効にする
    -   `CLONE_NEWUTS`: ホスト名とNISドメイン名を隔離
    -   `CLONE_NEWPID`: プロセスID番号空間を隔離
    -   `CLONE_NEWNS`: マウント名前空間（ファイルシステム）を隔離
    -   `CLONE_NEWNET`: ネットワーク名前空間を隔離（ネットワークスタックの分離）
4.  **IOストリーム**: Stdin、Stdout、Stderr を現在のプロセスに接続し対話を可能にする

### `child` 関数

`child` 関数は `run` によって作成された隔離環境内で実行される。
以下の手順でコンテナ環境を初期化しユーザーコマンドを実行する。

1.  **ホスト名の設定**: コンテナ内のホスト名を `mini-container` に設定する
2.  **loインターフェースの有効化**:
    -   新しいネットワーク名前空間ではループバックインターフェース（lo）がデフォルトでDOWN状態のためUPにする
    -   `chroot` 前のためホスト側の `ip` コマンドを利用して設定を行う
3.  **ルートファイルシステムの変更 (chroot)**:
    -   `syscall.Chroot` でプロセスのルートディレクトリを指定された `rootfs` に変更する
    -   `os.Chdir("/")` でカレントディレクトリを新しいルートへ移動する
4.  **procファイルシステムのマウント**: `ps` コマンド等が動作するように `/proc` をマウントする
5.  **コマンド実行 (exec)**: `syscall.Exec` を使用して現在のプロセスをユーザー指定のコマンドに置き換える（PID 1として動作）

## 使用方法

ルートファイルシステム（`rootfs`）を用意した上で以下のように実行する。

```bash
go run main.go run <rootfs> <cmd> [args...]
```

例:
```bash
go run main.go run ./rootfs /bin/sh
```

これにより `run` 関数がトリガーされ新しい名前空間で `child` プロセスが生成され指定したコマンドが隔離環境内で実行される。
